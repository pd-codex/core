# Core

Core 0.2 is a browser-first game prototype about changing the bit-level state of a running HCS08 microcontroller.

This repository is being initialized with the existing Core 0.2 static website. The deployment files will live at the repository root.

## GitHub Pages

After the site files are uploaded, configure Settings > Pages > Deploy from a branch > main > / (root).

The repository's visibility has not been changed. GitHub Pages availability for a private organization repository depends on the organization's GitHub plan.
